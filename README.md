##Airbnb Clone

A full-stack accommodation booking web application inspired by Airbnb, built using Node.js, Express.js, MongoDB, and EJS.

 ##About the Project

This project is a web application where users can explore property listings and view accommodation details. It demonstrates server-side rendering, RESTful routing, database integration, and CRUD operations.

##Features

- Browse property listings
- View individual property details
- Create and manage listings
- Server-side rendered pages using EJS
- RESTful routes with Express.js
- MongoDB database integration
- Organized MVC-style project structure

 ##Tech Stack

Backend: Node.js, Express.js
Database: MongoDB
Templating: EJS
Frontend: HTML, CSS, JavaScript, Bootstrap (if used)
Version Control: Git and GitHub

## Installation and Setup

1. Clone the repository:

   bash
   git clone https://github.com/sharyu13/airbnb-clone.git
   

2. Navigate to the project directory:

   bash
   cd airbnb-clone
   

3. Install dependencies:

   bash
   npm install
   

4. Create a `.env` file and add the environment variables required by the application.

5. Start the application using the start command defined in `package.json`.
 ##Environment Variables

Keep database credentials, API keys, and other secrets in your local `.env` file. Never commit these secrets to GitHub.
